# Criterios de publicación y privacidad

Esta vitrina demuestra capacidades sin publicar información operativa ni identificar clientes.

## Contenido permitido

- Descripción del producto y responsabilidades de su arquitectura.
- Decisiones de diseño, localización y metodología de validación.
- HTML, CSS y JavaScript de demostración sin conexiones al sistema real.
- Marca propia y un proyecto de ejemplo explícitamente ficticio.

## Contenido excluido

- Nombres, perfiles, correos, teléfonos, capturas o materiales de clientes.
- Credenciales, claves, hashes de contraseñas, enlaces privados y tokens.
- Configuración de producción, respaldos, exportaciones de base y registros de actividad.
- Código operativo de autenticación, administración, archivos, base de datos y correo.
- Snapshots internos completos y documentación con rutas de infraestructura.

## Publicación de cambios

Revisar tanto el contenido nuevo como lo que permanece del repositorio anterior. Borrar un archivo en un commit no lo quita del historial. Si una revisión identifica contenido que no debe seguir publicado, la limpieza del historial requiere una acción expresa y coordinada; terceros pueden conservar copias previas.

No convertir esta vitrina en una copia del hosting. Las futuras muestras deben usar datos inventados y declarar qué funciones son simuladas. No afirmar que una revisión puede garantizar ausencia total de riesgos.
